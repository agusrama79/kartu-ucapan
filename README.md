# KarsaKartu — Pembuat Undangan & Kartu Ucapan Digital Personal

Aplikasi web interaktif pembuat undangan dan kartu ucapan digital modern dengan **118 template tematik berkarakter**, efek visual FX dinamis, kustomisasi studio langsung, serta fitur simpan dan bagikan link secara instan.

---

## ✨ Fitur Utama

1. **118 Template Tematik Unik:**
   - **Kategori Kartu Ucapan:** Ulang tahun, kelulusan, anniversary, hari raya (Idul Fitri, Natal, Imlek), ucapan terima kasih, lekas sembuh, apresiasi sahabat, dan pencapaian karir.
   - **Kategori Undangan Acara:** Pernikahan adat & modern, pertunangan, aqiqah, syukuran rumah baru, pesta ulang tahun, peluncuran produk, gala dinner, webinar, reuni, dan workshop.
2. **Animasi & Visual FX Dinamis:**
   - Efek partikel melayang, kilau bintang, kembang api, floating confetti, aurora ambient glow, dan transisi halus berbasis CSS/Canvas.
3. **Studio Kustomisasi Lengkap:**
   - Kustomisasi instan: Nama penerima, judul acara/kartu, pesan personal, pengirim, waktu, tanggal, lokasi acara, dan catatan RSVP.
   - Pilihan tipografi elegan (Cinzel, Playfair Display, Dancing Script, Plus Jakarta Sans).
4. **Pratinjau Langsung & Interaktif:**
   - Sinkronisasi real-time antara formulir input dan kanvas kartu interaktif.
   - Tombol buka kartu interaktif, suara instan, dan sebaran confetti.
5. **Simpan & Bagikan Link:**
   - Ekspor tautan unik untuk dikirimkan melalui WhatsApp, Telegram, atau media sosial.
   - Metadata Open Graph siap pratinjau media sosial.
6. **Aksesibilitas & Desain Responsif:**
   - Layout modular berbasis 8px, mobile-first, dan optimal pada tampilan desktop.
   - Standar kontras WCAG AA dan dukungan navigasi keyboard ramah pengguna.

---

## 🛠️ Teknologi

- **HTML5:** Struktur semantik, aksesibilitas ARIA.
- **CSS3:** Custom design tokens, animasi transform/opacity, CSS Grid & Flexbox, efek visual responsif.
- **JavaScript (ES6+):** Vanilla JS modular, state management lokal, URL payload sharing.
- **Pustaka Eksternal:** [Canvas-Confetti](https://www.npmjs.com/package/canvas-confetti), Google Fonts.

---

## 🚀 Cara Menjalankan Secara Lokal

Buka file `index.html` langsung di peramban web modern, atau jalankan menggunakan server HTTP lokal:

```bash
# Menggunakan Python
python3 -m http.server 8080

# Atau menggunakan Node.js
npx serve .
```

Kemudian akses melalui browser di `http://localhost:8080`.
